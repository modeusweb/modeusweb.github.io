# MODEUS — Personal Portfolio

A dark, editorial personal portfolio and developer-tools showcase for **Anton
Nikonorov** (`modeusweb`). It presents four browser-based developer tools
alongside a concise introduction and capabilities overview.

**Live site:** https://modeusweb.github.io/

Built with Next.js, React, TypeScript and Tailwind CSS, and hosted on GitHub
Pages.

## Updating content

All editable content lives in two central files — never edit copy or URLs
inside components:

- **`lib/site-config.ts`** — name, wordmark, role, contact email, GitHub
  handle, and social links.
- **`lib/projects.ts`** — the project entries (description, category,
  technologies, demo and repository links, visual style).

## Before launch

- [ ] Confirm the **GitHub profile URL**.
- [ ] Verify each **project demo & repo link** in `lib/projects.ts`, especially

- [ ] Confirm the **name** and **role**; optionally add verified social links.
